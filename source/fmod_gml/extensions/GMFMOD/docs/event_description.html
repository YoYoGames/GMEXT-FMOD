Event Description¶

FMOD Object: Studio::EventDescription


This module holds functionality related to descriptions of FMOD Studio Events.

Event descriptions belong to banks and can be queried after the relevant bank has been loaded. Event descriptions may be retrieved via path or GUID lookup, or by enumerating all descriptions in a bank.

Functions¶

This module offers a collection of functions designed to address specific tasks and provide utilities for various purposes. Explore the available functions to make the most of the functionalities provided by this module.

fmod_studio_event_description_create_instance¶

FMOD Function: Studio::EventDescription::createInstance


This function creates a playable instance, returning a handle to the new EventInstance object.

When an event instance is created, any required non-streaming sample data is loaded asynchronously.

Use fmod_studio_event_description_get_sample_loading_state to check the loading status.

Sample data can be loaded ahead of time with fmod_studio_event_description_load_sample_data or fmod_studio_bank_load_sample_data. See Sample Data Loading for more information.


Syntax:

fmod_studio_event_description_create_instance(event_desc_ref)
Argument Type Description
event_desc_ref Real A reference to an EventDescription.


Returns:

Real

fmod_studio_event_description_set_callback¶

FMOD Function: Studio::EventDescription::setCallback


This function sets a callback for every instance of this event description.

An instance uses this callback unless it has one of its own, set with fmod_studio_event_instance_set_callback - an instance-level callback replaces this one entirely for that instance, rather than both firing. Instances that already exist when you call this function are covered too, not just ones created afterwards.

The callback runs on the frame after FMOD raised it, on the same thread as the rest of your game code.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

fmod_studio_event_description_set_callback(event_desc_ref, callback=undefined, callback_mask)
Argument Type Description
event_desc_ref Real A reference to an EventDescription.
callback Function The function to call when the callback fires. Omit it to clear the current callback.
callback_mask FmodStudioEventCallbackType A bitfield of the callback types to receive.


Returns:

Real


Triggers:

Callback

Key Type Description
event_instance_ref Real The EventInstance that raised the callback.
type FmodStudioEventCallbackType The callback type that fired.
properties Struct The payload for this callback type, or undefined for the types that carry none. FmodStudioEventCallbackType.TimelineMarker gives a FmodStudioTimelineMarkerProperties, TimelineBeat a FmodStudioTimelineBeatProperties, NestedTimelineBeat a FmodStudioTimelineNestedBeatProperties, CreateProgrammerSound and DestroyProgrammerSound a FmodStudioProgrammerSoundProperties, PluginCreated and PluginDestroyed a FmodStudioPluginInstanceProperties, and StartEventCommand the EventInstance reference of the event that was started.

fmod_studio_event_description_set_user_data¶

FMOD Function: Studio::EventDescription::setUserData


This function sets an integer user value on this object.

Note

While FMOD supports arbitrary User Data, this function only stores a 64-bit integer. To attach a GML value, keep it in a struct, array or ds_map of your own and store its key or index here. On 32-bit platforms the value must fit in 32 bits; one that does not is rejected with FmodResult.InvalidParam and nothing is stored.


Syntax:

fmod_studio_event_description_set_user_data(event_desc_ref, user_data)
Argument Type Description
event_desc_ref Real A reference to an EventDescription.
user_data Real The integer value to store on this object.


Returns:

Real
